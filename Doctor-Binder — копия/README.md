# Doctor Binder v2.1

Рабочая папка проекта: `D:\Doctor-Binder`.

Скрипт для AutoHotkey **v2** — биндер для медицинской RP-игры (SAMP GTA).

## Запуск

Запустите **`run-binder.cmd`** или **`google.ahk`** через установленный
AutoHotkey v2. Все остальные файлы подключаются к нему автоматически.

Для комфортной работы рекомендуется открывать именно `D:\Doctor-Binder` в редакторе.
Старый каталог `D:\--arena-01a01942-repo` оставлен временно, потому что Windows
не позволила переименовать папку во время активной сессии редактора.

## UI-дизайн

Окно 1200×736: верхняя панель, вертикальная навигация слева (240 px) и
рабочая область справа. Интерфейс выполнен в стиле **Dark Premium / Medical Enterprise**: почти чёрный
фон (`#080A0F`), спокойные поверхности карточек, тонкие холодные рамки,
аккуратная типографика, много воздуха и очень мягкие cyan-акценты (`#38BDF8`),
которые используются только как сигнал состояния или действия.

- Полное описание токенов и компонентов — `UI_IMPROVEMENTS.md`.
- Что именно изменил редизайн — `UI_REDESIGN_NOTES.txt`.
- Статический предпросмотр главного экрана — `docs/index.html`
  (открывается в браузере, на работу скрипта не влияет).

Дизайн-система живёт в двух файлах: токены — `lib/02_Globals.ahk` (`THEME`),
компоненты (кнопки, поля, карточки, статусы) — `lib/03_UI.ahk`.
Callback-функции и рабочая логика биндов не менялись.

## Структура (разбит на модули)

```
google.ahk                 ← ГЛАВНЫЙ файл: настройки, хоткеи, запуск
lib\
  01_Constants.ahk         ← константы (версия, лимиты, пути)
  02_Globals.ahk           ← все глобальные переменные
  03_UI.ahk                ← кнопки, ховер-эффекты, тёмная тема
  04_Utils.ahk             ← вспомогательные функции
  05_Notify.ahk            ← всплывающие уведомления
  06_Filters.ahk           ← фильтры биндов
  07_Profiles.ahk          ← загрузка/сохранение профилей
  08_Overlay.ahk           ← внутриигровой оверлей
  09_Chat.ahk              ← слежение за чатом, СМС, упоминания
  10_MainGui.ahk           ← главное окно
  11_BindList.ahk          ← список биндов, захват клавиш
  12_Editor.ahk            ← редактор бинда
  13_Sending.ahk           ← отправка сообщений, регистрация хоткеев
  14_Settings.ahk          ← сохранение/загрузка настроек
  15_Menus.ahk             ← радиальное меню, выбор бинда
  16_Telegram.ahk          ← статистика запуска в Telegram
```

Модули в `lib\` **не запускаются отдельно** — они подключаются к `google.ahk`
через директиву `#Include`.

## Как это работает

- `google.ahk` — тонкий файл: вверху подключает все модули, внизу — горячие
  клавиши и блок запуска (`LoadConfig()`, `BuildMainGui()` и т.д.).
- Порядок `#Include` не важен для функций (AutoHotkey v2 регистрирует их при
  загрузке скрипта), поэтому функции можно свободно перемещать между модулями.

## Настройка Telegram (опционально)

Отправка статистики запуска отключена, пока нет файла `telegram.ini`:

1. Скопируйте `telegram.ini.example` → переименуйте в `telegram.ini`.
2. Впишите туда свой токен бота и chat_id (получить токен — у @BotFather).
3. Файл `telegram.ini` не публикуйте (он уже в `.gitignore`).

## Автосохранение, бэкап конфига и лог

- **Автосохранение** — изменения сохраняются автоматически (интервал в
  настройке `autoSaveInterval`, по умолчанию 60 сек). Включается/выключается
  настройкой `autoSave`.
- **Бэкап конфига** — перед каждым сохранением `doctor_config.ini` копируется в
  папку `backups\` с меткой времени (хранятся последние 10 копий).
- **Лог ошибок** — все сбои пишутся в `doctor_log.txt` рядом со скриптом.
