Doctor Binder v2.1 — Premium UI redesign (Dark Premium / Medical Enterprise)
============================================================================

ЦЕЛЬ
    Превратить обычный dark utility UI в визуально дорогое медицинское
    enterprise-приложение. Функциональность, логика, формат данных биндов,
    хоткеи, автосохранение и импорт/экспорт профилей НЕ менялись.

ЧТО ИЗМЕНЕНО
------------
1. THEME (lib/02_Globals.ahk)
   - Новая палитра: bg #080A0F, surface #0D1016, elevated #111722,
     hover #151D28, border #202833/#344252, text #F2F4F7/#9AA4B2/#626D7B,
     accent #38BDF8, success #35C98A, danger #E66B83.
   - Радиусы уменьшены до 6/10/12, добавлены токены поля ввода
     (field, fieldBorder), accentSoft, btnPrimary и шрифтовые токены.
   - Все старые имена токенов сохранены — сторонний код не сломан.

2. Базовые контролы (lib/03_UI.ahk)
   - Кнопки: новая палитра стилей (по умолчанию тёмная поверхность + тонкая
     рамка + светлый текст), подложка под кнопкой для чистых углов,
     левое выравнивание с правым глифом, очень мягкое свечение у primary.
   - Новый компонент InputField/CreateInput: у Edit снят WS_EX_CLIENTEDGE
     (белая рамка Windows), добавлены рамка, поверхность, hover и cyan-focus
     с мягким кольцом. Наружу отдаётся тот же Gui.Edit с тем же v-именем.
   - Новые компоненты: CreateCard, CreateCardHeader (с номером 01/02/03),
     CreateFieldLabel, StatusDot (единая система состояний), StyleCheckbox.
   - ResolveUIFont(): Segoe UI Variable Text с откатом на Segoe UI.
   - Hover-опрос PollButtonHover теперь обслуживает и поля ввода.

3. Главное окно (lib/10_MainGui.ahk)
   - Шапка 60px: знак «+», DOCTOR BINDER, MEDICAL OPERATIONS CONSOLE · v2.1,
     справа ● SYSTEM READY и muted-статус AUTOSAVE ON/OFF.
   - Навигация: спокойные вкладки, активная — cyan-текст, тонкая cyan-рамка,
     мягкое свечение + плавный индикатор (анимация сохранена).
   - Заголовки страниц: слим-вариант (иконка, заголовок, подзаголовок,
     статус справа, разделитель) вместо тяжёлой карточки.
   - Обзор: три карточки 01 ЛИЧНОЕ ДЕЛО / 02 ТЕКУЩИЙ ПАЦИЕНТ /
     03 БЫСТРОЕ УПРАВЛЕНИЕ, единый вертикальный ритм, больше воздуха.
   - Текущий пациент стал полноценным Patient Status Panel:
     крупное поле ID, статусы WAITING / ACTIVE / ERROR, отображение в чате,
     формат вставки.
   - Быстрое управление — action-панель со строками и правыми глифами
     (→ ↻ ↓ ↑ ?) + блок горячих клавиш.
   - Нижний action/status bar: ● ALL CHANGES SAVED / ● UNSAVED CHANGES,
     «Отменить» + primary «СОХРАНИТЬ».
   - Бинды/Настройки/Статистика/Справка: премиальные поля, спокойные кнопки,
     карточки метрик с тонкой рамкой, боковые меню в едином стиле.

4. Прочее
   - Редактор бинда (12_Editor), редактор правил и фильтров, окно захвата
     клавиши, уведомления — переведены на новые компоненты и токены.
   - Из UI-строк убраны эмодзи (в GDI они рендерятся чёрными силуэтами).
   - Кнопки сохранения стали primary (cyan) вместо зелёных, тексты приведены
     к единому виду: СОХРАНИТЬ / СОХРАНИТЬ ИЗМЕНЕНИЯ / СОХРАНЕНО.

ЧТО НЕ МЕНЯЛОСЬ
---------------
   - Callback-функции, имена контролов (v-имена), формат doctor_config.ini,
     логика биндов, хоткеи, автосохранение, профили, статистика, оверлей.

ПРОВЕРКА
--------
   - tools/check_project.py — баланс скобок, дубли функций, эмодзи: чисто.
   - Дополнительно прогнаны линтеры вызовов функций и строк опций контролов.
   - ВНИМАНИЕ: среда разработки — Linux без AutoHotkey v2, полноценный
     GUI smoke-test выполнить нельзя. На Windows прогоните вручную:
     вкладки, поля, кнопки, ID пациента, сохранение/загрузку профиля,
     список биндов, автосохранение.

ПРЕДПРОСМОТР ДИЗАЙНА
