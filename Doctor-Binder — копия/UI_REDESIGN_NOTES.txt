Doctor Binder v2.1 — UI redesign patch

Изменено:
- Убрана принудительная перерисовка MainGui при переключении страниц.
- Убрана анимация/движение кнопок при клике и hover.
- Кнопки CreateStyledButton/CreateOutlineBtn приведены к единому скруглённому компоненту.
- Hover теперь реально меняет фон кнопки и курсор, без смещения элемента.
- При запуске принудительно выбирается Главная.
- Навигация синхронизируется с текущей страницей без WinRedraw.
- Убраны тёмные подложки под текстовыми labels в редакторе бинда.
- Убран тёмный прямоугольник под текстом раздела «Оверлей» в справке.
- Удалена неиспользуемая MainApplyDoctor, которая ссылалась на отсутствующий контрол MainDoctorName.

Важно:
Среда разработки не содержит Windows + AutoHotkey v2 runtime, поэтому фактический GUI smoke-test на Windows выполнить здесь невозможно. Перед заменой рабочего биндера рекомендуется сохранить резервную копию текущей папки.
